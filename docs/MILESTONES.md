## 里程碑變更規則

1. 新功能先指定 milestone 與驗收條件，再改變核心 state 或場景資料格式。
2. 若改變存檔 schema，需在同一變更中加入向前遷移與舊存檔測試。
3. 規劃中的項目只有在程式、測試和 UI 一起完成後才可標記完成。
4. 延期或取消項目需記錄原因及重新評估條件。
