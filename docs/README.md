# 維運文件索引

本資料夾記錄《夜嵐夜市》的現行架構、重要設計決策、軟體設計與交付里程碑。文件描述本專案自己的資料模型與實作邊界，供後續維護、測試及擴充使用。

| 文件 | 用途 |
| --- | --- |
| [架構說明](ARCHITECTURE.md) | 模組責任、相依方向、執行環境、狀態與渲染架構 |
| [軟體設計說明（SDD）](SOFTWARE_DESIGN.md) | 遊戲流程、核心資料、領域規則、存檔、場景與驗證方式 |
| [設計決策紀錄](DECISIONS.md) | 影響後續實作的決策、理由、限制與重新評估條件 |
| [里程碑與路線圖](MILESTONES.md) | 已完成內容、目前基線、分階段計畫及驗收條件 |

## 維護規則

- 以程式碼與測試為實際行為的最終依據；文件描述設計意圖，不取代執行驗證。
- 修改存檔欄位、遊戲階段、會計結帳週期、攤位／店面資料或部署入口時，同步更新相應文件。
- 未實作的規劃需標為「規劃中」或「待評估」，不可寫成現行功能。
- 會計科目代碼是遊戲內部代碼；任何報表與保險數字均屬簡化模擬。
