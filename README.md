# 夜嵐夜市｜港邊夜市經營模擬

《夜嵐夜市》是一款以台灣港邊夜市為舞台的 2.5D 斜視角經營模擬網頁遊戲。從小攤起步，親自安排菜單、備料、設備與排班，在每日營運、客人故事與夜市事件之間，慢慢打造能長久經營的店家。

**線上遊玩：** [夜嵐夜市｜ChatGPT Site](https://yelan-night-market-game.duskylark33.chatgpt.site/)

## 遊戲特色

- **可操作的 2.5D 夜市場景**：旋轉、縮放並瀏覽斜視角場景；客人與店員在攤位間活動，燈籠、爐火、煙霧、雨勢與活動效果會隨營運呈現。點選攤位即可開啟工作台。
- **每日營運管理**：開門前管理菜單、食材庫存、設備升級與人員排班；開門後接待顧客、處理訂單與突發客訴。
- **有得有失的營運事件**：燈節與觀光活動可能帶來客流及活動 Bonus；雨勢、供應商調價、停電、衛生稽查與奧客事件則會影響成本、服務或口碑，玩家需做出取捨。
- **持續性的成本與投資**：納入攤位租金、擴店／併購租金、人事、食材、水電瓦斯、清潔、客訴、貸款利息等營運項目。設備購置、攤位改造與經營權會建立資產資料，並依耐用年限提列直線折舊或攤銷。
- **每週經營決策**：每完成七夜進入週轉決策，可選擇擴店、招聘、併購同業或保留現金；投資會持續影響日後客流、固定成本與資產。
- **業態專屬分店商品與價格**：接手港口炸物、山海果物、花生糖舖或彈珠小屋，各自有專屬商品、備料單位、進貨成本、售價與設備加價；不再讓不同店面共用同一套商品與定價。
- **可管理的接手分店**：併購後的攤位會成為獨立店點，不再只是品牌聯盟的被動加成。可逐店補該業態的專屬備料、升級設備、開店或暫停；由老闆照看的分店每夜最多接一筆生意。
- **店長自動營運與總部決策**：主店加上至少一間正在營業的分店後，可在週決策聘請店長（招募訓練 NT$ 420 起、每夜薪資 NT$ 62）。店長自動排班、提高接待量並處理例行營運；備料售罄會自動暫停分店，玩家仍需補貨。每週若遇設備異常、分店客訴或慶典邀約，玩家只需決定維修、補償或活動投入等重大事項；也可解除店長、改回自營。
- **品牌聯盟與供應優勢**：擴店並接手兩間同屬餐飲或遊戲體驗的分店，可建立夜市品牌聯盟，取得客流與採購優惠等長期效果。
- **持續流動的遊戲世界**：故事與市集日曆每 30 夜進入下一期循環，週決策持續進行；第 30 夜不是遊戲結束，而是新的報表期間與故事里程碑。
- **營運紀錄與財務報表**：可查前一日日記簿與會計分錄、每週試算工作底稿；每 30 夜結算綜合損益表、權益變動表、資產負債表及現金流量表，也可檢視會計科目表與資產清冊。
- **瀏覽器自動存檔**：遊戲進度儲存在目前瀏覽器的本機儲存空間。

## 會計模型說明

遊戲採用**IFRS 導向的教育性模擬**，以借貸平衡分錄整理營運資料，並呈現主要財務報表。科目代碼為本專案的內部編號，不是 IFRS 官方科目編碼；目前模型亦未涵蓋完整財報附註、所有稅務與會計政策選擇或其他綜合損益項目，不應視為正式會計或稅務工具。

## 本機執行

專案使用原生 JavaScript，無需安裝第三方套件或建置流程。使用 Node.js 執行測試：

```bash
npm test
```

可使用任一靜態檔案伺服器提供 `dist/` 目錄，例如：

```bash
python -m http.server 4173 --directory dist
```

接著瀏覽 `http://localhost:4173`。

## 專案結構

- `dist/index.html`、`dist/styles.css`：遊戲頁面結構與視覺樣式。
- `dist/data.js`：菜單、顧客、事件、價格與場景設定。
- `dist/campaign.js`：30 夜故事日曆、市集公告卡、每週決策與結局條件。
- `dist/state.js`：遊戲存檔、遷移、營運狀態、成本與事件規則。
- `dist/accounting.js`：內部科目表、借貸分錄、資產折舊／攤銷與報表結算。
- `dist/game.js`：可測試的遊戲規則與瀏覽器互動流程。
- `dist/scene.js`：斜視投影、相機、場景合成、命中測試與操作控制。
- `dist/scene/objects.js`、`dist/scene/effects.js`：場景物件與事件特效繪製。
- `dist/ui.js`：以 DOM 節點建立的管理面板、對話框與報表介面。
- `dist/app.js`：瀏覽器啟動入口。
- `tests/game.test.js`：遊戲規則、存檔、相機、經濟循環與會計報表測試。

## 驗證

執行 `npm test` 可驗證客訴選項、庫存耗盡、設備效果、存檔與舊檔遷移、市集公告卡、週轉貸款、同業聯盟、相機限制、跨越 30 夜持續營運、借貸平衡及報表勾稽等核心路徑。
