# 夜嵐夜市｜2.5D 經營模擬

以台灣港邊夜市為舞台的 vanilla-JS 2.5D 經營遊戲。斜俯視 Canvas 場景可旋轉、縮放與暫停；點擊攤位打開整合工作台，管理備料、設備和排班。

## 專案結構

- `dist/data.js`：料理、客人、事件、營運成本、場景路徑與相機參數。
- `dist/campaign.js`：三十夜事件／手記時間線、每週經營決策與多種結局。
- `dist/state.js`：存檔遷移、localStorage、行事曆事件、成本帳本與損益預估。
- `dist/scene.js`：等角投影、畫面合成、命中測試與相機控制。
- `dist/scene/objects.js`：攤位、道具、店員與客人繪製。
- `dist/scene/effects.js`：燈節、雨勢、供應商與客訴等場景特效。
- `dist/ui.js`：以 DOM 節點建立的營運面板、攤位工作台和點餐／客訴介面。
- `dist/game.js`：可單元測試的遊戲規則與瀏覽器互動控制。
- `dist/app.js`：瀏覽器入口；`dist/index.html` 與 `dist/styles.css` 為頁面和樣式。
- `.openai/hosting.json`：既有 Sites 靜態部署設定。
- `tests/game.test.js`：無外部依賴的遊戲規則測試。
- `index.html`：GitHub Pages 根目錄入口，導向 `dist/index.html`。

## 執行與測試

直接以現代瀏覽器開啟 `dist/index.html`，遊戲進度存在瀏覽器 `localStorage`。測試不需安裝依賴：

```powershell
node --test tests/game.test.js
```

## 營運內容

帳本包含基本租金、拓店／併購租金、人事薪資、水電瓦斯、食材採購與耗用、客訴補償及退款。主線共三十夜，每夜有獨立事件敘事；燈節 Bonus、奧客、突雨、漁貨行情、街頭音樂、市集折扣、跳電及設備巡查都會影響當夜營運。

每完成七夜，玩家可選擇擴大店家、招聘人手、併購攤販或保留現金；選擇會改變客流、口碑、舒適度與後續固定成本。第三十夜依口碑、熟客、盈餘與拓展策略導向多種正面或負面結局，並可開始新周目。

## 操作

- 拖曳旋轉場景、滾輪縮放；聚焦場景後可用方向鍵、加減鍵和 Enter／空白鍵操作。
- 點「攤位管理」查看庫存、設備、班表與成本，再進入各管理頁籤。
- 點擊正在接待的客人接單；客訴可安撫、招待或退款。
- 可暫停場景動畫；系統啟用減少動態效果時，場景會自動停格。輕柔音效可自行開啟／關閉。
