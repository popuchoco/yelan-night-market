# 夜嵐夜市｜2.5D 經營模擬

以台灣港邊夜市為舞台的單頁網頁遊戲。使用 Canvas 繪製斜俯視 2.5D 場景，包含可旋轉相機、移動顧客與店員、攤位管理、備料、設備、排班及營運事件。

## 執行

直接在現代瀏覽器開啟 `index.html` 即可遊玩。進度儲存在瀏覽器的 `localStorage`，不需安裝依賴或啟動後端服務。

## 操作

- 拖曳場景旋轉視角，滾輪縮放；也可使用畫面上的相機按鈕。
- 點擊中央攤位管理備料、設備與人員排班。
- 點擊正在接待的顧客接單與出餐。

## 遊戲系統

包含攤位租金、人事、水電與瓦斯、食材採購及耗用成本；節慶加成、雨勢與奧客等事件會改變當晚營運。
